# Money

Live app: https://antoleod.github.io/Money/

Money is a browser-based virtual savings wallet for tracking a 365-day savings challenge.

## Related tools

- [RustChain](https://rustchain.org) — an experimental Proof-of-Antiquity network with native wallet and reward flows. It is a useful reference project when exploring how digital wallets, rewards, and transparent transaction histories can be modeled beyond this app's local savings tracker.
